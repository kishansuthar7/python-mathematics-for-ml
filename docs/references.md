# Reference Library

These resources complement implementation practice. Use references to understand concepts, then write your own explanations and code.

## Primary mathematics textbook

- **Deisenroth, Faisal, and Ong — *Mathematics for Machine Learning*.** The authors provide the book and supplementary materials through the official site: <https://mml-book.github.io/>. This is the primary reference for linear algebra and later topics that support ML.

## University-level linear algebra

- **MIT OpenCourseWare — 18.06SC Linear Algebra.** Lectures, notes, assignments, and exams: <https://ocw.mit.edu/courses/18-06sc-linear-algebra-fall-2011/>.
- **3Blue1Brown — Essence of Linear Algebra.** Geometric intuition and visual explanations: <https://www.3blue1brown.com/topics/linear-algebra>.

## Official Python and numerical-computing documentation

- Python tutorial: <https://docs.python.org/3/tutorial/>.
- NumPy absolute beginner guide: <https://numpy.org/doc/stable/user/absolute_beginners.html>.
- NumPy `dot`: <https://numpy.org/doc/stable/reference/generated/numpy.dot.html>.
- NumPy `linalg.norm`: <https://numpy.org/doc/stable/reference/generated/numpy.linalg.norm.html>.
- Matplotlib tutorials: <https://matplotlib.org/stable/tutorials/index.html>.

## Machine learning resources for later modules

- scikit-learn getting started: <https://scikit-learn.org/stable/getting_started.html>.
- PyTorch tutorials: <https://docs.pytorch.org/tutorials/>.

## Responsible use of external material

- Write notebook explanations in your own words.
- Record the source of external datasets, figures, and adapted code where relevant.
- Follow the source's licence and usage terms.
- Do not present copied repository code as your own implementation.
